SweaxDrop 1.0.1 fixes what the first tests with real phones (a Redmi Note 13 and an iPhone) turned up.

**Downloads**

| File | For |
|---|---|
| `SweaxDrop-1.0.1-Windows-Setup.exe` | Windows 10 and 11. Installs over 1.0.0. Asks once for administrator rights to keep its firewall rule for `sweaxdrop.exe`. |
| `SweaxDrop-1.0.1-Android.apk` | Android 10 and newer. Installs over 1.0.0 (same signing key). |
| `SweaxDrop-1.0.1-iOS-unsigned.ipa` | iPhone, iOS 15 and newer, to sign with your own Apple ID ([steps](https://github.com/Sweax3169/sweaxdrop#iphone)). |
| `SHA256SUMS.txt` | Checksums of the files above. |

**Fixed**

- **Browser client: the QR link never finished loading.** Opening the link from the QR code ran into a variable named like the browser's own `history` before it existed, so the page stopped on its loading screen. It now connects straight away.
- **Browser client: typing the computer's address showed demo devices.** Without a QR code the page fell back to the website's demo, with made-up devices that nothing could be sent to. It now asks you to scan the QR code on the computer.
- **Android: photos and videos sent from the gallery arrived as numbers** (`1000179895.mp4`): the photo picker hides real names. They are now named after the moment they were taken, the way the camera names them (`VID_20261102_013455.mp4`).
- **Android: receiving many small files was slow**, about 30 ms per file, because every file was created through Android's media provider. Files up to 4 MiB are now written directly into Download, Pictures or Movies; larger files still go through the provider so half-received videos never show up in the gallery.
- **Android: "Stay ready in the background" was forgotten** after the app restarted. It is now restored when the app opens.
- The Android package no longer carries old copies of the interface.
- The benchmark report computes MB/s from the median time, so speed and time always agree.

**Measured with a real phone** (Redmi Note 13 on a home router's Wi-Fi, PC on Ethernet, the 1.0.0 apps, one run each): one 1 GiB file PC → phone in 40.7 s (26.4 MB/s), 200 files of 723 MB in 23.0 s (32.9 MB/s), four videos and a photo phone → PC, 253 MB, in 6.25 s (40.5 MB/s). Details in the [README](https://github.com/Sweax3169/sweaxdrop#with-a-real-phone-over-wi-fi).

The Windows installer is not code-signed, so SmartScreen may ask for confirmation; compare the file with `SHA256SUMS.txt`.
